    SAHOOL Astronomical Calendar Service¶

    خدمة التقويم الفلكي الزراعي¶

    نظرة عامة¶

    خدمة التقويم الفلكي التقليدي اليمني للزراعة. تجمع بين الحسابات الفلكية الدقيقة والمعرفة الزراعية التقليدية اليمنية المتوارثة عبر آلاف السنين.

    المعلومات التقنية¶

    المعلومة القيمة
    المنفذ 8111
    اللغة Python 3.11
    الإطار FastAPI
    الإصدار 15.5.0

    المميزات¶

    🌙 مراحل القمر (8 مراحل)¶

    المرحلة الاسم العربي مناسب للزراعة
    new_moon المحاق ❌
    waxing_crescent الهلال المتزايد ✅
    first_quarter التربيع الأول ✅
    waxing_gibbous الأحدب المتزايد ✅
    full_moon البدر ✅
    waning_gibbous الأحدب المتناقص ❌
    last_quarter التربيع الأخير ❌
    waning_crescent الهلال المتناقص ❌

    القاعدة:

    • القمر المتزايد: مناسب لزراعة المحاصيل الورقية والثمرية
    • القمر المتناقص: مناسب لزراعة الجذور والتقليم

    ⭐ المنازل القمرية (28 منزلة)¶

    أفضل المنازل للزراعة (درجة 8-10):¶

    المنزلة البرج الدرجة المحاصيل الموصى بها
    الثريا الثور 10/10 جميع المحاصيل
    سعد السعود الدلو 10/10 جميع المحاصيل
    الشرطين الحمل 9/10 قمح، شعير، ذرة
    السماك العذراء 9/10 جميع المحاصيل
    الدبران الثور 8/10 فواكه، أشجار
    العواء العذراء 8/10 حبوب، بقوليات
    الذراع السرطان 8/10 خيار، بطيخ
    سعد بلع الجدي 8/10 أشجار، فواكه

    أسوأ المنازل للزراعة (درجة 2-3):¶

    المنزلة البرج الدرجة ملاحظة
    الشولة العقرب 2/10 تجنب جميع الأنشطة
    الطرف الأسد 2/10 منزلة حارة
    الجبهة الأسد 2/10 للحصاد فقط
    القلب العقرب 3/10 لمكافحة الآفات

    • تحويل دقيق من ميلادي إلى هجري
    • أسماء الأشهر الـ 12

    البرج العنصر الخصوبة الدرجة
    السرطان ماء خصبة جداً 10/10
    العقرب ماء خصبة جداً 9/10
    الحوت ماء خصبة جداً 9/10
    الثور أرض خصبة جداً 9/10

    البرج العنصر الخصوبة الدرجة
    الأسد نار جافة جداً 2/10
    الجوزاء هواء جافة 3/10

    🌾 المواسم الزراعية اليمنية¶

    الموسم الأشهر المحاصيل الرئيسية الأنشطة
    الصيف (Sayf) 6,7,8 ذرة، دخن، سمسم زراعة الحبوب
    الخريف (Kharif) 9,10,11 بن، عنب حصاد، تجفيف
    الشتاء (Shita) 12,1,2 قمح، شعير، خضروات زراعة القمح
    الربيع (Rabi) 3,4,5 فواكه، بن غرس الأشجار

    📜 الأمثال الزراعية اليمنية¶

    أمثال عامة:¶

    المثل المعنى التطبيق
    "إذا طلعت الثريا عشاءً، فاكفِ يدك من الماء" انتهاء موسم الري الصيفي توقيت الري
    "الزرع في الثريا، والحصاد في الجوزاء" أفضل أوقات الزراعة والحصاد توقيت عام
    "اللي يزرع في القمر المتزايد، محصوله متزايد" الزراعة في القمر المتزايد أفضل مرحلة القمر
    "من زرع في المحاق، حصد البواق" تجنب الزراعة في المحاق تجنب الزراعة
    "في الشولة لا تزرع ولا تحول" تجنب الزراعة في منزلة الشولة منزلة سيئة
    "سعد السعود، يخرج البرد من العود" انتهاء البرد وبداية الدفء توقيت الموسم

    النجوم المهمة:¶

    النجم الاسم الإنجليزي شهر الطلوع الأهمية
    سهيل Canopus أغسطس بداية الأمطار والبرودة
    الثريا Pleiades مايو أفضل وقت للزراعة
    السماك Spica أبريل نجم الربيع والخصوبة

    نقاط النهاية (API Endpoints)¶

    التقويم¶

    GET /v1/today              - البيانات الفلكية لليوم
GET /v1/date/{date}        - البيانات لتاريخ محدد
GET /v1/week               - التوقعات الأسبوعية
GET /v1/best-days          - أفضل الأيام لنشاط معين

    الفلك¶

    GET /v1/moon-phase         - مرحلة القمر
GET /v1/lunar-mansion      - المنزلة القمرية
GET /v1/zodiac             - البرج الشمسي
GET /v1/hijri              - التاريخ الهجري

    المراجع¶

    GET /v1/lunar-mansions     - قائمة المنازل الـ 28
GET /v1/hijri-months       - الأشهر الهجرية
GET /v1/zodiac-farming     - الأبراج والخصوبة
GET /v1/seasons            - المواسم اليمنية
GET /v1/current-season     - الموسم الحالي

    المحاصيل¶

    GET /v1/crops              - قائمة المحاصيل المدعومة
GET /v1/crop-calendar/{crop} - تقويم محصول معين

    الحكمة اليمنية¶

    GET /v1/proverbs           - جميع الأمثال الزراعية
GET /v1/proverbs/today     - مثل اليوم
GET /v1/proverbs/crop/{crop} - أمثال المحصول
GET /v1/proverbs/mansion/{mansion} - أمثال المنزلة
GET /v1/stars              - النجوم المهمة
GET /v1/stars/{star}       - معلومات نجم
GET /v1/wisdom/today       - الحكمة اليومية الشاملة

    التكامل¶

    GET /v1/integration/weather - دمج مع بيانات الطقس

    التكامل مع الخدمات الأخرى¶

    مع خدمة الطقس (weather-advanced)¶

    curl "http://localhost:8111/v1/integration/weather?location_id=sanaa"

    يدمج:

    • البيانات الفلكية (المنزلة، القمر، البرج)
    • بيانات الطقس (درجة الحرارة، الرطوبة)
    • توصيات متكاملة

    مع خدمة الري الذكي (irrigation-smart)¶

    يمكن استخدام توصيات التقويم الفلكي لتحديد أفضل أوقات الري:

    • القمر المتناقص: ري أقل (النبات يخزن الماء)
    • القمر المتزايد: ري أكثر (النبات ينمو)

    مع خدمة صحة المحاصيل (crop-health-ai)¶

    دمج المعرفة التقليدية مع الذكاء الاصطناعي:

    • توقيت الرش حسب المنزلة
    • تجنب الرش في المنازل غير المناسبة

    التشغيل¶

    محلياً¶

    cd apps/services/astronomical-calendar
pip install -r requirements.txt
python src/main.py

    Docker¶

    docker build -t sahool-astronomical-calendar .
docker run -p 8111:8111 sahool-astronomical-calendar

    قواعد الزراعة التقليدية¶

    1. قاعدة القمر¶

    ✅ القمر المتزايد (من المحاق إلى البدر):
   - زراعة المحاصيل الورقية (خس، سبانخ)
   - زراعة المحاصيل الثمرية (طماطم، خيار)
   - التسميد الورقي

❌ القمر المتناقص (من البدر إلى المحاق):
   - زراعة الجذور (بصل، ثوم، بطاطس)
   - التقليم
   - الحصاد والتخزين

    2. قاعدة المنازل¶

    ✅ أفضل المنازل:
   - الثريا (10/10): جميع المحاصيل
   - سعد السعود (10/10): مباركة لكل شيء
   - السماك (9/10): خصوبة عالية

❌ أسوأ المنازل:
   - الشولة (2/10): ذنب العقرب - تجنب كل شيء
   - الطرف (2/10): منزلة حارة

    3. قاعدة الأبراج¶

    ✅ أبراج الماء والأرض:
   - السرطان، العقرب، الحوت: ممتازة للزراعة
   - الثور، الجدي: خصبة جداً

❌ أبراج النار والهواء:
   - الأسد: أسوأ برج للزراعة
   - الجوزاء، القوس: جافة
