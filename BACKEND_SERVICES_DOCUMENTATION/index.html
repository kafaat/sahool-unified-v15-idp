    معادلة FAO-56 Penman-Monteith¶

    ET0 = [0.408 × Δ × (Rn - G) + γ × (900/(T+273)) × u2 × (es - ea)] / [Δ + γ × (1 + 0.34 × u2)]

حيث:
- Rn: صافي الإشعاع (MJ/m²/day)
- G: تدفق الحرارة في التربة
- T: متوسط درجة الحرارة (°م)
- u2: سرعة الرياح على 2م (م/ث)
- es: ضغط البخار المشبع (kPa)
- ea: ضغط البخار الفعلي (kPa)
- Δ: ميل منحنى ضغط البخار
- γ: ثابت التبخر (kPa/°م)

    المؤشرات النباتية¶

    def calculate_ndvi(nir, red):
    """NDVI = (NIR - Red) / (NIR + Red)"""
    return (nir - red) / (nir + red)

def calculate_evi(nir, red, blue):
    """EVI = 2.5 × (NIR - Red) / (NIR + 6×Red - 7.5×Blue + 1)"""
    return 2.5 * (nir - red) / (nir + 6*red - 7.5*blue + 1)

def calculate_ndwi(nir, swir):
    """NDWI = (NIR - SWIR) / (NIR + SWIR)"""
    return (nir - swir) / (nir + swir)

def calculate_lai(ndvi):
    """LAI from NDVI empirical relationship"""
    return -ln((0.69 - ndvi) / 0.59) / 0.91

    NDWI > 0 إجهاد مائي
    EVI > 0.4 بنية مظلة ضعيفة
    LAI > 3 تغطية أوراق متناثرة
