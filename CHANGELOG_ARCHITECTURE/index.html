    3. قواعد Offline الجديدة¶

    # كل شاشة Mobile يجب أن:
- تعمل بدون اتصال (على الأقل بآخر بيانات)
- تعرض مؤشر "البيانات قديمة" عند اللزوم
- تسمح بتنفيذ المهام وحفظها محلياً
- لا تعتمد runtime على خدمات التحليل

    4. Pipeline التحويل الرسمي¶

    Analysis Output (NDVI, Weather, AI)
        ↓
Bridge Normalization
        ↓
Risk Scoring + Explanation
        ↓
Action Template Selection
        ↓
Field Task Creation
        ↓
Mobile Sync (Offline-ready)
        ↓
Execution + Proof
        ↓
Audit Trail

    🔧 التغييرات التقنية¶

    إصلاحات Docker¶

    1. إزالة field_core dependency¶

    # docker-compose.yml
# قبل:
admin_dashboard:
  depends_on:
    - field_core  # ❌ خدمة legacy

# بعد:
admin_dashboard:
  depends_on:
    - crop_health_ai
    - virtual_sensors

    2. إصلاح USER directive في Dockerfiles¶

    # Node.js Alpine (استخدام node user الموجود)
RUN chown -R node:node /app
USER node

# Python Debian (إنشاء sahool user)
RUN groupadd --system --gid 1000 sahool && \
    useradd --system --uid 1000 --gid sahool sahool
USER sahool

    3. إصلاح COPY path في billing-core¶

    # قبل:
COPY ../shared /app/shared/  # ❌ خارج build context

# بعد:
# Note: shared libraries will be mounted at deployment

    إصلاحات CI/CD¶

    1. GitHub Actions permissions¶

    permissions:
  contents: read
  issues: write
  pull-requests: write

    2. Flutter dependencies¶

    # pubspec.yaml
intl: ^0.19.0 # للتوافق مع flutter_localizations
mockito: ^5.4.5 # للتوافق مع Dart 3.6.0

    Sync Failure Rate ~5% <1%
