    🏛️ مبادئ SAHOOL المعمارية¶

    Field-First, Analysis-Serves-Field¶

    المبدأ الأساسي¶

    المنصة ميدانية، والتحليل يخدم الميدان.

    القواعد الذهبية الثلاث¶

    1️⃣ الميدان لا يتوقف¶

    أي شاشة في Mobile يجب أن تعمل بدون اتصال.

    مسموح:

    • عرض آخر NDVI محفوظ
    • إظهار مؤشر "البيانات قديمة"
    • تنفيذ المهام وحفظها محلياً

    ممنوع:

    • شاشة لا تفتح بدون API
    • زر تنفيذ يعتمد على استجابة خادم
    • رسالة "لا يوجد اتصال" كشاشة نهائية

    2️⃣ التحليل ينتج توصيات، لا قرارات¶

    Analysis Output → Bridge Transformation → Field Task

    مسموح:

    NDVI Analysis → "إجهاد مائي محتمل" → "نفّذ ري خلال 48 ساعة"

    ممنوع:

    NDVI Analysis → مباشرة للمستخدم بدون ترجمة

    3️⃣ كل مخرج تحليلي له Fallback¶

    Online: Real-time Analysis
Offline: Cached + Stale Indicator

    تصنيف الخدمات¶

    🟢 Field-Critical (الأولوية 1)¶

    • لا تتوقف أبداً
    • Offline required
    • Restart: always
    الخدمة السبب
    field-service إدارة الحقول
    billing-core التحقق من الاشتراك
    astronomical-calendar التوقيت الزراعي
    notification-service التنبيهات الحرجة

    🟡 Bridge (الأولوية 2)¶

    • تحويل وتوزيع
    • Offline optional
    • Restart: on-failure
    الخدمة الوظيفة
    indicators-service تحويل البيانات لمؤشرات
    yield-engine توصيات الإنتاجية
    irrigation-smart توصيات الري
    fertilizer-advisor توصيات التسميد

    🔵 Analysis (الأولوية 3)¶

    • يمكن تأخيرها
    • Async processing
    • Restart: on-failure
    الخدمة الوظيفة
    satellite-service تحليل الأقمار الصناعية
    crop-health-ai تشخيص الأمراض
    crop-growth-model نماذج النمو
    weather-advanced التنبؤات المتقدمة

    معايير قبول الميزات¶

    ✅ الميزة مقبولة إذا:¶

    • [ ] تعمل Offline (على الأقل بآخر بيانات)
    • [ ] لديها Fallback UX واضح
    • [ ] التحليل ينتج Recommendation ثم Task
    • [ ] لا يوجد Hard runtime dependency على Analysis

    ❌ الميزة مرفوضة إذا:¶

    • [ ] تتطلب اتصال دائم
    • [ ] تعرض بيانات تحليلية خام بدون ترجمة
    • [ ] تعطل الـ UX عند غياب الاتصال

    أمثلة تطبيقية¶

    ✅ صحيح¶

    Weather API → ET0 Calculation → "اسقِ 25mm صباح الغد"
                              → Task في Mobile
                              → يعمل offline

    ❌ خطأ¶

    Weather API → JSON Response → عرض مباشر في UI
                            → يفشل offline
