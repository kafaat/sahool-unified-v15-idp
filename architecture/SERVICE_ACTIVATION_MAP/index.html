    Transform dormant analysis services into field-actionable value through Tasks, Alerts, and Playbooks.

    ✅ الخدمات المُفعّلة | Activated Services¶

    1. satellite-service (Port: 8090)¶

    الغرض: تحليل صور الأقمار الصناعية وتحويلها لتنبيهات ميدانية

    Endpoint الوصف ActionTemplate
    POST /v1/analyze-with-action تحليل مع إجراء ✅
    GET /v1/fields/{id}/ndvi قيمة NDVI ❌ (تحليل فقط)
    GET /v1/fields/{id}/anomalies الشذوذات ❌ (تحليل فقط)

    المخرجات Field-First:

    {
  "action_template": {
    "type": "field_inspection",
    "what": "فحص منطقة الشذوذ في الحقل",
    "why": "انخفاض NDVI بنسبة 15% في الزاوية الشمالية",
    "when": { "deadline": "2024-01-22", "optimal_window": "صباحاً" },
    "how": ["توجه للمنطقة المحددة", "افحص الأوراق", "صوّر الأعراض"],
    "fallback": "إذا لم تستطع الزيارة: أرسل عامل للفحص",
    "badge": { "type": "satellite_reading", "label_ar": "قراءة قمر صناعي" }
  }
}

    2. virtual-sensors (Port: 8085)¶

    الغرض: حسابات IoT بديلة للمناطق الريفية بدون أجهزة

    Endpoint الوصف ActionTemplate
    POST /v1/irrigation/recommend-with-action توصية ري مع إجراء ✅
    GET /v1/quick-check-with-action فحص سريع مع إجراء ✅
    POST /v1/calculate-et0 حساب ET₀ ❌ (حساب فقط)
    POST /v1/estimate-soil-moisture تقدير رطوبة التربة ❌ (تقدير فقط)

    المخرجات Field-First:

    {
  "action_template": {
    "type": "irrigation_urgent",
    "what": "إجراء ري طارئ",
    "why": "رطوبة التربة المقدرة منخفضة (22%)",
    "when": {
      "deadline": "6 ساعات",
      "optimal_window": "المساء بعد غروب الشمس"
    },
    "how": ["شغّل المضخة الرئيسية", "اسقِ لمدة 15 دقيقة", "راقب تشرب التربة"],
    "fallback": "إذا لم تتوفر المضخة: ري يدوي عميق حول الجذور",
    "badge": { "type": "virtual_estimate", "label_ar": "تقدير افتراضي" },
    "confidence": 0.75
  }
}

    ملاحظة: Confidence أقل (0.75) بسبب غياب IoT الفعلي

    3. crop-growth-timing (Port: 8098)¶

    الغرض: قرارات "متى" للعمليات الزراعية

    Endpoint الوصف ActionTemplate
    POST /v1/analyze-timing تحليل توقيت النمو ✅
    GET /v1/growth-stages/{crop} مراحل النمو ❌ (مرجع)
    GET /health فحص الصحة ❌

    المخرجات Field-First:

    {
  "action_template": {
    "type": "fertilization_timing",
    "what": "تطبيق الدفعة الأولى من السماد",
    "why": "المحصول في مرحلة التفريع (V3) - الوقت المثالي للتسميد",
    "when": {
      "deadline": "2024-01-25",
      "optimal_window": "صباحاً قبل ارتفاع الحرارة"
    },
    "how": [
      "استخدم سماد NPK 15-15-15",
      "الكمية: 50 كجم/هكتار",
      "وزّع بالتساوي حول النباتات",
      "اسقِ بعد التسميد مباشرة"
    ],
    "fallback": "إذا لم يتوفر NPK: استخدم يوريا 25 كجم/هكتار",
    "badge": { "type": "growth_model", "label_ar": "نموذج نمو" }
  }
}

    4. irrigation-smart (Port: 8086)¶

    الغرض: جدولة الري الذكي

    Endpoint الوصف ActionTemplate
    POST /v1/schedule جدولة الري ✅
    GET /v1/fields/{id}/next الري القادم ✅

    5. notification-service (Port: 8083)¶

    الغرض: توصيل الإشعارات للتطبيق المحمول

    Component الوصف
    NATS Subscriber استقبال أحداث التحليل
    Firebase Push إرسال إشعارات
    SMS Gateway رسائل SMS للطوارئ
    Webhook إشعارات خارجية

    المواضيع المشترك فيها | Subscribed Topics:

    • sahool.analysis.completed
    • sahool.alerts.created
    • sahool.actions.acknowledged

    📋 الخدمات المخططة | Planned Services¶

    1. yield-prediction (Port: 8091) - الأولوية: 🔴 عالية¶

    الغرض: توقع الإنتاجية وتنبيهات ما قبل الحصاد

    المدخلات:

    {
  "field_id": "field-001",
  "crop_type": "wheat",
  "current_growth_stage": "flowering",
  "weather_forecast": { ... },
  "historical_yields": [ ... ]
}

    المخرجات المطلوبة:

    {
  "predicted_yield_kg_ha": 3200,
  "confidence": 0.82,
  "action_template": {
    "type": "pre_harvest_alert",
    "what": "استعداد للحصاد",
    "why": "المحصول سيكون جاهزاً خلال 14 يوم - الإنتاج المتوقع 3.2 طن/هكتار",
    "when": { "deadline": "2024-02-05", "optimal_window": "أسبوع قبل الموعد" },
    "how": [
      "جهّز معدات الحصاد",
      "تأكد من توفر العمالة",
      "رتّب مكان التخزين",
      "تواصل مع المشتري"
    ],
    "fallback": "إذا تأخر الحصاد: راقب علامات الجفاف الزائد"
  }
}

    ROI: حماية 100% من قيمة المحصول

    المخرجات المطلوبة:

  "expected_lai": 3.5,
  "stress_detected": true,
  "action_template": {
    "type": "early_stress_alert",
    "what": "فحص إجهاد مبكر",
    "why": "LAI أقل من المتوقع بنسبة 20% - علامات إجهاد مبكر",
    "when": { "deadline": "48 ساعة", "optimal_window": "صباحاً" },
    "how": [
      "افحص لون الأوراق",
      "تحقق من رطوبة التربة",
      "ابحث عن علامات آفات",
      "صوّر المنطقة المتأثرة"
    ],
    "fallback": "إذا لم تجد السبب: استشر المهندس الزراعي",
    "badge": {
      "type": "satellite_estimate",
      "label_ar": "تقدير من القمر الصناعي"
    }
  }
}

    ROI: كشف مبكر = تدخل مبكر = خسائر أقل

    📡 خريطة NATS Topics¶

    sahool.
├── analysis.
│   ├── completed          # تحليل اكتمل → notification-service
│   ├── failed             # تحليل فشل → monitoring
│   └── progress           # تقدم التحليل → dashboard
│
├── alerts.
│   ├── created            # تنبيه جديد → notification-service
│   ├── acknowledged       # تم الاعتراف → tracking
│   └── escalated          # تصعيد → SMS gateway
│
├── actions.
│   ├── assigned           # إجراء مُسند → mobile app
│   ├── acknowledged       # تم الاعتراف → tracking
│   ├── executed           # تم التنفيذ → analytics
│   └── expired            # انتهت الصلاحية → re-alert
│
└── fields.
    ├── updated            # تحديث الحقل → refresh all
    └── status_changed     # تغيير الحالة → dashboard

    🚦 أولويات التفعيل | Activation Priorities¶

    المرحلة 1 - مكتمل ✅¶

    1. ~~satellite-service~~ → ActionTemplate endpoints
    2. ~~virtual-sensors~~ → ActionTemplate + Badge system
    3. ~~crop-growth-timing~~ → Python bridge for timing decisions
    4. ~~notification-service~~ → NATS subscriber

    المرحلة 2 - مكتمل ✅¶

    1. ~~yield-prediction~~ → Pre-harvest alerts + ActionTemplate
    2. GET /api/v1/yield/predict-with-action/:fieldId - تنبيهات ما قبل الحصاد
    3. GET /api/v1/yield/harvest-readiness/:fieldId - فحص جاهزية الحصاد
    4. Badge: yield_model / maturity_model
    5. ~~lai-estimation~~ → Early stress detection + ActionTemplate
    6. GET /api/v1/lai/stress-detection/:fieldId - الكشف المبكر عن الإجهاد
    7. GET /api/v1/lai/anomaly-check/:fieldId - فحص شذوذ LAI
    8. Badge: satellite_estimate / satellite_anomaly

    المرحلة 3 - مخطط 📋¶

    1. disaster-assessment → Playbook generation
    2. weather-advanced → Weather-driven scheduling
