### Component Descriptions | وصف المكونات

| Component | Description (EN) | Description (AR) |
|-----------|------------------|------------------|
| **Mobile App** | Flutter-based offline-first agricultural field app | تطبيق الحقل الزراعي بـ Flutter يعمل دون اتصال |
| **Web Dashboard** | Next.js dashboard for analytics and monitoring | لوحة معلومات Next.js للتحليلات والمراقبة |
| **Admin Portal** | React admin portal for system management | بوابة إدارة React لإدارة النظام |
| **Kong Gateway** | API gateway for auth, rate limiting, routing | بوابة API للمصادقة وتحديد المعدل والتوجيه |
| **PostgreSQL** | Main database with PostGIS for geospatial | قاعدة البيانات الرئيسية مع PostGIS للجغرافيا المكانية |
| **NATS** | Event bus for async messaging | ناقل الأحداث للرسائل غير المتزامنة |
| **Redis** | Caching and session management | التخزين المؤقت وإدارة الجلسات |
