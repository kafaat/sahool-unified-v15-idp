# دليل التسميد | Fertilization Knowledge Base

مرجع شامل لإدارة تغذية المحاصيل في منطقة الشرق الأوسط وشبه الجزيرة العربية.

## قواعد عامة للتسميد | General Fertilization Rules

### القاعدة الذهبية: 4R

| R | English | العربية | التوضيح |
|---|---------|---------|---------|
| **Right Source** | المصدر الصحيح | اختيار السماد المناسب للمحصول والتربة |
| **Right Rate** | المعدل الصحيح | حسب تحليل التربة واحتياج المحصول |
| **Right Time** | الوقت الصحيح | مطابقة لمراحل النمو والطلب |
| **Right Place** | المكان الصحيح | قريب من الجذور النشطة |

### أهمية تحليل التربة | Soil Testing Importance

- تحليل التربة **قبل كل موسم** أساس التسميد العلمي
- تجنب التسميد العشوائي الذي يهدر المال ويلوث البيئة
- المعامل المعتمدة تقدم توصيات دقيقة حسب المحصول
