## نظام التحكم ICON 5 | ICON 5 Control System {#icon-5}

### نظرة عامة | Overview

Valley ICON 5 هو الجيل الخامس من لوحات التحكم الذكية لأنظمة الري المحوري. يوفر تحكماً كاملاً عن بُعد عبر تطبيق AgSense 365.

### المواصفات الفنية | Technical Specifications

| المواصفة | التفاصيل |
|----------|----------|
| **الشاشة** | 10.1" LCD ملونة تعمل باللمس، مقاومة للماء IP65 |
| **المعالج** | ARM Cortex، ذاكرة 512MB RAM |
| **الاتصال** | 4G LTE + Wi-Fi + Satellite (اختياري) |
| **GPS** | دقة ±1 متر (RTK اختياري لدقة ±2 سم) |
| **الاستشعار** | ضغط، تدفق، موقع، سرعة، اتجاه، درجة حرارة |
| **التخزين** | سجل 5 سنوات من بيانات التشغيل |
| **الطاقة** | 120/240V AC + بطارية احتياطية 12V |
| **التشغيل** | -20°C إلى +60°C |

### وظائف ICON 5 | ICON 5 Functions

#### 1. التحكم الأساسي | Basic Control

```
التشغيل/الإيقاف ← START/STOP
الاتجاه ← Forward / Reverse
السرعة ← 0-100% (المؤقت Timer)
بدء من زاوية ← Auto Start at Angle
إيقاف عند زاوية ← Auto Stop at Angle
رطب/جاف ← Wet/Dry Sector Selection
```

#### 2. الجدولة | Scheduling

- **برنامج يومي**: حتى 8 دورات يومية مختلفة
- **برنامج أسبوعي**: جدول مختلف لكل يوم
- **برنامج موسمي**: تعديل تلقائي حسب مرحلة النمو
- **إيقاف مطر**: إيقاف تلقائي عند هطول مطر (مستشعر مطر)
- **إيقاف رياح**: إيقاف عند تجاوز سرعة الرياح الحد المحدد

#### 3. التنبيهات | Alerts

| التنبيه | الوصف | الأولوية |
|---------|-------|----------|
| توقف المحور | عدم حركة أثناء التشغيل | حرج |
| انخفاض ضغط | أقل من الحد المعين | حرج |
| تدفق غير طبيعي | أعلى أو أقل من المعدل | تحذير |
| نهاية دورة | اكتمال 360° | معلوماتي |
| صيانة مجدولة | حسب ساعات التشغيل | استشاري |
| فصل اتصال | انقطاع الاتصال بالشبكة | تحذير |
| درجة حرارة عالية | > 55°C في لوحة التحكم | تحذير |
| جهد منخفض | بطارية احتياطية < 11V | تحذير |

#### 4. تقارير ICON 5 | Reports

- **تقرير التشغيل**: ساعات تشغيل، عدد الدورات، كمية المياه
- **تقرير الطاقة**: استهلاك kWh، تكلفة تقديرية
- **تقرير الأعطال**: سجل التنبيهات والتوقفات
- **تقرير VRI**: خريطة التطبيق الفعلي vs الوصفة
- **تقرير GPS**: مسار المحور وسجل المواقع

### AgSense 365 | تطبيق التحكم عن بُعد

AgSense 365 هو التطبيق الموحد الذي يدمج 4 منصات سابقة (AgSense, Valley 365, PrecisionKing, PivoTrac).

**المزايا**:

## الري بمعدل متغير VRI | Variable Rate Irrigation {#vri}

### المبدأ | Principle

VRI يطبق كميات مختلفة من المياه في مناطق مختلفة من الحقل بناءً على:
- اختلاف نوع التربة (رملية مقابل طينية)
- اختلاف التضاريس (مرتفعات ومنخفضات)
- اختلاف حالة المحصول (من بيانات NDVI)
- مناطق غير مزروعة (طرق، أبنية، قنوات)

### أنواع VRI | VRI Types

#### Speed Control VRI (البسيط)

- **الآلية**: تغيير سرعة المحور حسب الزاوية
- **الدقة**: قطاعات (sector-based)
- **عدد المناطق**: 360 قطاع (1 درجة لكل قطاع)
- **التكلفة**: منخفضة (ترقية برمجية فقط)
- **التوفير**: 5-15% من المياه

```
مثال: حقل دائري 50 هكتار
- القطاع 0-90°: تربة رملية → سرعة 70% (تطبيق أكثر)
- القطاع 90-180°: تربة طميية → سرعة 100% (تطبيق عادي)
- القطاع 180-270°: مرتفع → سرعة 85% (تطبيق متوسط)
- القطاع 270-360°: منخفض → سرعة 110% (تطبيق أقل لتجنب التجمع)
```

#### Zone Control VRI (المتقدم)

- **الآلية**: فتح/إغلاف فوهات فردية أو مجموعات
- **الدقة**: صمام واحد لكل 3-6 فوهات
- **عدد المناطق**: 100-2500 منطقة (حسب عدد الصمامات)
- **التكلفة**: عالية (صمامات كهربائية لكل منطقة)
- **التوفير**: 15-30% من المياه
- **المكونات**: صمامات Valley BaseStation2 + ICON 5

### إنشاء وصفة VRI | Creating VRI Prescription

```
المدخلات:
├── خريطة التربة (soil map)
├── خريطة NDVI (من الأقمار أو الطائرات بدون طيار)
├── خريطة التضاريس (DEM)
├── بيانات مستشعرات رطوبة التربة
└── حدود الحقل (field boundary)
    ↓
المعالجة:
├── تقسيم الحقل إلى مناطق إدارية (management zones)
├── حساب ETc لكل منطقة
├── تحديد عمق الري المطلوب لكل منطقة
└── تحويل إلى أوامر VRI (سرعة أو صمامات)
    ↓
المخرجات:
├── خريطة وصفة (Prescription Map)
├── ملف VRI (لتحميله على ICON 5)
└── تقرير مقارنة: تطبيق موحد vs VRI
```

### حساب العائد على الاستثمار | ROI Calculation

| البند | بدون VRI | مع VRI | الفرق |
|-------|----------|--------|-------|
| استهلاك المياه (م³/هـ/موسم) | 6,000 | 4,800 | -20% |
| تكلفة المياه (ريال/هـ) | 1,800 | 1,440 | -360 |
| تكلفة الطاقة (ريال/هـ) | 800 | 640 | -160 |
| الإنتاجية (طن/هـ) | 4.5 | 4.9 | +8.9% |
| **التوفير الإجمالي** | - | - | **1,260 ريال/هـ/موسم** |
| **تكلفة نظام VRI** | - | - | **15,000-40,000 ريال** |
| **فترة الاسترداد** | - | - | **2-4 مواسم** |

## تقسيم الحقل وإدارة المناطق | Field Zoning & Management Zones {#field-zoning}

### مفهوم مناطق الإدارة | Management Zone Concept

تقسيم الحقل إلى مناطق متجانسة من حيث التربة والتضاريس والإنتاجية لتطبيق معاملات مختلفة (ري، تسميد، بذر).

### مصادر بيانات التقسيم | Zoning Data Sources

| المصدر | البيانات | الدقة | التكلفة |
|--------|---------|-------|---------|
| **NDVI (Sentinel-2)** | مؤشر الغطاء النباتي | 10م/بكسل | مجاني |
| **خرائط الإنتاجية** | Yield Maps من الحصادة | 1-3م | متاح مع الحصادة |
| **EM Survey** | التوصيل الكهربائي للتربة | 5-10م | متوسط |
| **DEM (تضاريس)** | ارتفاعات وميول | 1-30م | مجاني-متوسط |
| **تحليل تربة** | خواص التربة (pH, EC, NPK) | نقطي | مرتفع |
| **مستشعرات IoT** | رطوبة تربة فورية | نقطي | مرتفع |

### خوارزمية التقسيم | Zoning Algorithm

```
1. جمع البيانات المكانية (NDVI, DEM, soil EC)
2. تطبيع البيانات (normalize 0-1)
3. تجميع بخوارزمية K-Means أو Fuzzy C-Means
4. تحديد عدد المناطق الأمثل (2-5 مناطق عادةً)
5. تنعيم الحدود (spatial smoothing)
6. مراجعة ميدانية وتعديل
7. تصدير كخريطة شكلية (shapefile) لنظام VRI
```

### أنواع التقسيم | Zone Types

| نوع التقسيم | الهدف | مصدر البيانات الرئيسي |
|-------------|-------|----------------------|
| **مناطق الري** | تطبيق VRI | خريطة التربة + NDVI |
| **مناطق التسميد** | تطبيق VRA (Variable Rate Application) | تحليل تربة + NDVI |
| **مناطق البذر** | كثافة بذر مختلفة | خريطة الإنتاجية + التربة |
| **مناطق المراقبة** | مراقبة الآفات والأمراض | NDVI + سجل تاريخي |

### محاكاة التقسيم | Zoning Simulation

يمكن لمنصة سهول محاكاة تأثير التقسيم قبل التطبيق الفعلي:

```
المدخلات:
├── حدود الحقل (GeoJSON)
├── خريطة NDVI حالية
├── بيانات تربة متاحة
└── معلمات المحور (طول، موقع المركز)
    ↓
المحاكاة:
├── تقسيم إلى 3 مناطق (مثال)
├── حساب ETc لكل منطقة
├── محاكاة VRI speed control
├── محاكاة VRI zone control
└── مقارنة مع تطبيق موحد
    ↓
المخرجات:
├── خريطة المناطق المقترحة
├── وفر المياه المتوقع (%)
├── تأثير الإنتاجية المتوقع (%)
├── تكلفة التطبيق
└── ROI وفترة الاسترداد
```

### تطبيقات المراقبة على المحور | Pivot Monitoring Applications

#### 1. كشف أعطال الفوهات | Nozzle Failure Detection

```
خريطة NDVI عالية الدقة (3-10م)
         ↓
كشف خطوط أو بقع جافة دائرية
         ↓
تحديد موقع الفوهة المعطلة (رقم الرشاش)
         ↓
تنبيه صيانة تلقائي
```

#### 2. تقييم انتظام التطبيق | Application Uniformity

```
مقارنة NDVI على طول نصف القطر
         ↓
CU (معامل الانتظام) المقدر
         ↓
تحديد مناطق الإفراط/النقص
         ↓
توصية بتعديل الرشاشات أو الضغط
```

#### 3. مراقبة تغطية الزاوية | Corner Coverage Monitoring

```
NDVI داخل الدائرة vs خارجها
         ↓
تقييم فعالية Corner Arm
         ↓
تحديد المساحة غير المخدومة
         ↓
تقدير الخسارة الإنتاجية في الزوايا
```

#### 4. سلسلة زمنية NDVI | NDVI Time Series

تحليل تطور المحصول عبر الموسم تحت المحور:
- كشف تأخر في النمو (قد يدل على مشكلة ري)
- مقارنة مع المعدل التاريخي
- تنبؤ بموعد الحصاد
- تقدير الإنتاجية

## الطاقة الشمسية للمحاور | Solar Energy for Pivots {#solar-energy}

### لماذا الطاقة الشمسية؟ | Why Solar?

- تكلفة الكهرباء = 30-50% من تكلفة تشغيل المحور
- المنطقة العربية: 2,000-2,500 ساعة شمسية/سنة
- الإشعاع الشمسي: 5-7 kWh/م²/يوم
- مزارع نائية بدون شبكة كهربائية

### التطبيقات | Applications

#### 1. تشغيل مضخة المحور بالطاقة الشمسية | Solar-Powered Pump

| المواصفة | التفاصيل |
|----------|----------|
| **قدرة المضخة** | 15-75 kW (حسب العمق والتدفق) |
| **ألواح مطلوبة** | 30-150 لوح (550W كل لوح) |
| **المساحة المطلوبة** | 200-800 م² |
| **الإنفرتر** | VFD (Variable Frequency Drive) شمسي |
| **التخزين** | مع بطاريات (ري 24 ساعة) أو بدون (ري نهاري فقط) |
| **التكلفة** | 50,000-200,000 ريال |
| **الاسترداد** | 3-5 سنوات |

#### 2. تشغيل محركات الأبراج بالطاقة الشمسية

- **استهلاك برج واحد**: 0.5-1.5 kW
- **محور 10 أبراج**: 5-15 kW
- **حل هجين**: شمسي + شبكة (تقليل 50-70% من تكلفة الطاقة)

#### 3. تشغيل ICON 5 والاتصالات

- **استهلاك لوحة التحكم**: 50-100 واط
- **لوح شمسي صغير + بطارية**: تشغيل مستمر بدون شبكة
- **مفيد في**: المزارع النائية، المواقع بدون كهرباء

### حسابات التصميم الشمسي | Solar Design Calculations

```
القدرة المطلوبة (kWp) = قدرة المضخة (kW) / معامل الأداء (0.75-0.85)

مثال: مضخة 30 kW
القدرة الشمسية = 30 / 0.80 = 37.5 kWp
عدد الألواح (550W) = 37.5 / 0.55 = 69 لوح
المساحة ≈ 69 × 2.8 م² = 193 م²
```

### مقارنة تكلفة الطاقة | Energy Cost Comparison

| مصدر الطاقة | تكلفة (ريال/kWh) | تكلفة سنوية (محور 50 هـ) | ملاحظات |
|-------------|-------------------|--------------------------|---------|
| شبكة كهربائية | 0.18-0.32 | 8,000-15,000 | أرخص لكن يحتاج توصيل |
| ديزل | 0.40-0.80 | 18,000-36,000 | متاح لكن مكلف |
| شمسي (بدون تخزين) | 0.05-0.10 | 2,200-4,500 | ري نهاري فقط |
| شمسي + بطاريات | 0.12-0.20 | 5,400-9,000 | ري 24 ساعة |
| هجين (شمسي + شبكة) | 0.10-0.15 | 4,500-6,750 | الأمثل اقتصادياً |

## التطبيقات والتكامل المتقدم | Advanced Applications {#applications}

### 1. Chemigation (التسميد والمعالجة عبر المحور)

تطبيق الأسمدة والمبيدات عبر نظام الري المحوري:

| نوع التطبيق | الأسمدة/المبيدات | النسبة | ملاحظات |
|-------------|-----------------|--------|---------|
| **Fertigation** | أسمدة سائلة (UAN-32, 10-34-0) | 5-20 لتر/هـ | ري + تسميد في نفس الوقت |
| **Herbigation** | مبيدات حشائش | حسب التسجيل | يحتاج فحص نوز بدون انسداد |
| **Insectigation** | مبيدات حشرية | حسب التسجيل | تطبيق موجه مع VRI |
| **Fungigation** | مبيدات فطرية | حسب التسجيل | فعال ضد الصدأ والبياض |

> **تحذير**: يجب تركيب صمام منع الرجوع (check valve) ونظام حقن معتمد لمنع تلوث مصدر المياه.

### 2. التحكم التلقائي بالمضخة | Automated Pump Control

```
مستشعر ضغط (عند المضخة + عند المحور)
         ↓
ICON 5 يرسل أمر تشغيل المضخة
         ↓
VFD يضبط سرعة المضخة حسب الطلب
         ↓
مراقبة مستمرة: ضغط + تدفق + استهلاك
         ↓
إيقاف تلقائي عند نهاية الدورة أو خلل
```

### 3. الطائرات بدون طيار + المحور | Drone + Pivot Integration

| الاستخدام | التفاصيل | الفائدة |
|-----------|----------|---------|
| **مسح NDVI عالي الدقة** | دقة 5 سم، كل حقل في < 30 دقيقة | وصفة VRI دقيقة |
| **رش موضعي** | DJI Agras أو XAG | معالجة بقع الآفات بدون رش كامل |
| **كشف أعطال** | تصوير حراري للأنابيب والفوهات | صيانة استباقية |
| **عد النباتات** | تصوير في مرحلة الإنبات | تقييم كثافة الزراعة |

### 4. التوأم الرقمي للمحور | Digital Twin for Pivot

محاكاة رقمية كاملة لنظام الري المحوري:

```
بيانات حقيقية (ICON 5 + IoT + طقس)
         ↓
نموذج المحور الرقمي:
├── موقع وزاوية المحور (GPS)
├── حالة كل فوهة (ON/OFF, flow rate)
├── معدل التطبيق الفعلي (mm/hr per zone)
├── خريطة الرطوبة المتوقعة
└── استهلاك الطاقة الفعلي vs المتوقع
         ↓
مخرجات:
├── تنبؤ بوقت الري القادم
├── كشف انحراف عن الوصفة
├── تحسين جدول الري
└── تخطيط الصيانة التنبؤية
```

### 5. الذكاء الاصطناعي والمحور | AI + Pivot

| التطبيق | النموذج | المدخلات | المخرجات |
|---------|---------|----------|----------|
| **تنبؤ ETc** | LSTM/Transformer | طقس + مرحلة نمو | ETc يومي لـ 7 أيام |
| **جدولة ذكية** | Reinforcement Learning | رطوبة + طقس + تعرفة طاقة | توقيت وكمية الري الأمثل |
| **كشف أعطال** | Anomaly Detection | ضغط + تدفق + GPS | تنبيه مبكر |
| **وصفة VRI** | Clustering + Regression | NDVI + تربة + DEM | خريطة وصفة محسنة |
| **تقدير إنتاجية** | Random Forest | NDVI + طقس + ري | طن/هكتار |

## التكامل مع منصة سهول | SAHOOL Platform Integration {#sahool-integration}

### بنية التكامل | Integration Architecture

```
Valley ICON 5 / AgSense 365
         ↓ (API / MQTT / Webhook)
iot-gateway (shared/integrations/)
         ↓
iot-service → NATS: sahool.iot.pivot.telemetry
         ↓
irrigation-smart → حساب VRI prescription
         ↓
vegetation-analysis-service → خريطة NDVI
         ↓
terrain-core-service → DEM وتقسيم المناطق
         ↓
digital-twin-engine → محاكاة المحور
         ↓
advisory-service → توصية ري شاملة
         ↓
notification-service → تنبيه المزارع (SMS/App)
```

### أحداث NATS المقترحة | Proposed NATS Events

| الحدث | الوصف | المشغل |
|-------|-------|--------|
| `sahool.pivot.cycle_started` | بدء دورة المحور | ICON 5 |
| `sahool.pivot.cycle_completed` | اكتمال دورة | ICON 5 |
| `sahool.pivot.alert.pressure_low` | انخفاض ضغط | مستشعر |
| `sahool.pivot.alert.stopped` | توقف غير متوقع | ICON 5 |
| `sahool.pivot.alert.wind` | تجاوز حد الرياح | محطة طقس |
| `sahool.pivot.vri.prescription_applied` | تحميل وصفة VRI | ICON 5 |
| `sahool.pivot.maintenance.due` | صيانة دورية مستحقة | جدول صيانة |
| `sahool.pivot.telemetry.update` | بيانات تشغيل دورية | كل 5 دقائق |
| `sahool.pivot.energy.solar_status` | حالة النظام الشمسي | إنفرتر |
