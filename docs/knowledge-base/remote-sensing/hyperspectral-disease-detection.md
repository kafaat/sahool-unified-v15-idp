# التصوير الطيفي العالي للكشف عن أمراض المحاصيل | Hyperspectral Imaging for Crop Disease Detection

## نظرة عامة | Overview

التصوير الطيفي العالي (Hyperspectral Imaging - HSI) يلتقط صوراً في مئات النطاقات الطيفية المتجاورة (عادة 200-400 نطاق)، مما يوفر بصمة طيفية فريدة لكل بكسل. هذا يتيح الكشف المبكر عن الأمراض النباتية قبل ظهور الأعراض المرئية بأسابيع.

Hyperspectral imaging captures images across hundreds of contiguous spectral bands (typically 200-400 bands), providing a unique spectral fingerprint for each pixel. This enables early detection of plant diseases weeks before visible symptoms appear.

### المقارنة مع التقنيات الأخرى | Comparison with Other Technologies

| التقنية | عدد النطاقات | الدقة الطيفية | الكشف المبكر | التكلفة |
|---------|-------------|--------------|-------------|---------|
| RGB (كاميرا عادية) | 3 | منخفضة | لا | منخفضة |
| Multispectral (متعدد الأطياف) | 4-12 | متوسطة | محدود | متوسطة |
| **Hyperspectral (فوق طيفي)** | **200-400** | **عالية جداً** | **نعم (2-4 أسابيع مبكراً)** | **عالية** |
| Thermal (حراري) | 1-2 | لا ينطبق | محدود (إجهاد مائي) | متوسطة |

## التطبيقات الزراعية الرئيسية | Key Agricultural Applications

### 1. كشف الأمراض الفطرية | Fungal Disease Detection

الأمراض الفطرية تغير التركيب الكيميائي للنبات قبل ظهور أعراض مرئية. التصوير الطيفي العالي يكشف هذه التغيرات من خلال:

- تغير امتصاص الكلوروفيل (680-740 نانومتر)
- تغير محتوى الماء في الأوراق (950-1050 نانومتر)
- تغير تركيب جدار الخلية (1100-1250 نانومتر)
- تغير محتوى الكاروتينويدات (500-550 نانومتر)

### 2. تصنيف أمراض الحمضيات | Citrus Disease Classification

> **بحث مرجعي**: Yu et al. (2025) - "Detection of fungal diseases in citrus fruits based on hyperspectral imaging"
> DOI: [10.1016/j.inpa.2025.02.006](https://doi.org/10.1016/j.inpa.2025.02.006)
> المجلة: Information Processing in Agriculture (INPA), IF: 7.4

هذه الدراسة الحديثة أثبتت فعالية التصوير الطيفي العالي في تصنيف ثلاث فئات من أمراض الحمضيات الفطرية + ثمار صحية:

| المرض | الاسم العلمي | مستوى الحجر الصحي | الكشف |
|-------|-------------|-------------------|-------|
| العفن الأخضر (Green Mold) | *Penicillium digitatum* | غير حجري | ✓ |
| العفن الأزرق (Blue Mold) | *Penicillium italicum* | غير حجري | ✓ |
| عفن القرنفل (Clove Rot / Diplodia) | *Diplodia natalensis* | **حجري** | ✓ |
| ثمار صحية (Healthy) | - | - | ✓ |

**النتائج الرئيسية**:
- دقة التصنيف: **92.50%** باستخدام 44 نطاقاً طيفياً مختاراً
- خوارزمية CARS اختارت **44 نطاقاً حساساً** من أصل 224 نطاقاً كاملاً
- تقليل الأبعاد حسّن الدقة بنسبة 1.87% مقارنة بالطيف الكامل
- النموذج خفيف الوزن مناسب للنشر على أجهزة الحافة (Edge Devices)

## بنية النموذج العصبي | Neural Network Architecture

### النموذج ثنائي الفرع | Dual-Branch Model

النموذج المقترح في Yu et al. (2025) يستخدم بنية ثنائية الفرع:

```
صورة طيفية عالية (H × W × 224/44 نطاق)
         ↓
    ┌────────────────┬──────────────────┐
    │  الفرع المكاني  │  الفرع الطيفي     │
    │ Spatial Branch  │ Spectral Branch  │
    ├────────────────┼──────────────────┤
    │ Conv 7×7, s=2  │ AdaptiveAvgPool  │
    │ + BN + ReLU    │      ↓           │
    │      ↓         │ FullyConnected   │
    │ MaxPool 3×3    │      ↓           │
    │      ↓         │ SE Block (r=0.25)│
    │ BasicBlock×1   │      ↓           │
    │ BasicBlock×2   │ Bi-LSTM (4, hid) │
    │ BasicBlock×2   │                  │
    │      ↓         │                  │
    │ SE Block (0.25)│                  │
    │ AdaptiveAvgPool│                  │
    │ Flatten        │                  │
    └───────┬────────┴──────┬───────────┘
            │  دمج (Concat) │
            └───────┬───────┘
                    ↓
            FullyConnected
                    ↓
            Class Output (4 فئات)
```

### المكونات الأساسية | Key Components

#### BasicBlock (كتلة أساسية)
```
Input (H×W×C) → Conv 3×3, s → BN → ReLU → Conv 3×3, s → BN → ReLU → Output (H×W×C)
                                                                  + Skip Connection
```

#### SE Block (كتلة الانتباه القنوي)
Squeeze-and-Excitation block لإعادة معايرة الأهمية النسبية للقنوات:
```
Input (H×W×C) → Global Avg Pool (1×1×C)
             → FC (C/r) → ReLU → FC (C) → Sigmoid
             → × (Channel-wise multiplication) → Output (H×W×C)
```
حيث `r = 4` (نسبة التقليل)

| وقت المعالجة | طويل | **أسرع بكثير** |

### النطاقات الطيفية الحساسة للأمراض | Disease-Sensitive Spectral Bands

## التحديات والقيود | Challenges and Limitations

### تحديات تقنية | Technical Challenges
- **حجم البيانات**: صورة طيفية واحدة قد تصل إلى عدة جيجابايت
- **تكلفة المعدات**: أجهزة التصوير الطيفي العالي مكلفة ($20,000-100,000+)
- **المعالجة**: تحتاج قدرة حسابية عالية لمعالجة 200+ نطاق

### حلول مقترحة | Proposed Solutions
- **اختيار النطاقات**: تقليل من 224 إلى 44 نطاقاً (تقليل 80% مع تحسين الدقة)
- **نماذج خفيفة**: بنية ثنائية الفرع مدمجة للنشر على أجهزة الحافة
- **معالجة تدريجية**: معالجة على مستوى الحقل بدلاً من المنطقة الكاملة
- **بدائل متعددة الأطياف**: استخدام نطاقات محددة بدلاً من الطيف الكامل

### التصنيف الخاطئ المعروف | Known Misclassification
- تشابه طيفي بين العفن الأخضر (*P. digitatum*) والعفن الأزرق (*P. italicum*)
- التمييز بين الإصابات الفطرية والإصابات الجسدية (physical damage)

## البحث المستقبلي | Future Research Directions

1. **توسيع فئات الأمراض**: شمول أمراض إضافية مثل التقرح البكتيري والتريستيزا
2. **الإصابات المعقدة**: كشف الإصابة بأكثر من مرض في نفس الثمرة
3. **الكشف الميداني**: نقل النماذج من المختبر إلى الحقل (Field deployment)
4. **التكامل مع RGB**: دمج البيانات الطيفية مع الصور العادية لتحسين الدقة
5. **Transfer Learning**: نقل النموذج إلى محاصيل أخرى (قمح، طماطم، نخيل)
