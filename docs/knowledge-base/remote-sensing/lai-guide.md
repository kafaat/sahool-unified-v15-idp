# دليل مؤشر مساحة الأوراق (LAI) | Leaf Area Index Guide

LAI هو إجمالي مساحة الأوراق (وجه واحد) لكل وحدة مساحة أرض (م2/م2). يحدد كثافة الغطاء النباتي وهو حاسم لتقدير اعتراض الضوء والتبخر-نتح والكتلة الحيوية واحتياجات مياه الري.

## المفهوم والتعريف | Concept

```
LAI = إجمالي مساحة الأوراق (م2) / مساحة الأرض (م2)

أمثلة:
- LAI = 0: تربة عارية
- LAI = 1: غطاء خفيف (أوراق تغطي مرة واحدة)
- LAI = 4: غطاء كثيف (أوراق بـ 4 طبقات تراكمية)
- LAI = 8: غابة كثيفة
```

## حساب LAI من الأقمار الصناعية | Satellite-Based LAI Estimation

### الطرق المعتمدة | Methods

| الطريقة | الدقة | التعقيد | البيانات المطلوبة |
|---------|-------|---------|-------------------|
| **علاقة NDVI-LAI تجريبية** | متوسطة | بسيط | [[ndvi-interpretation\|NDVI]] فقط |
| **نموذج الانعكاس (PROSAIL)** | عالية | معقد | نطاقات متعددة |
| **منتج Sentinel-2 LAI (Biophysical)** | جيدة | متوسط | L2A [[sentinel-guide\|Sentinel-2]] |
| **شبكة عصبية (ML)** | عالية | معقد | بيانات تدريب |

### علاقة NDVI-LAI التجريبية | Empirical NDVI-LAI Relationship

```
LAI = -ln((NDVImax - NDVI) / (NDVImax - NDVImin)) / k_ext

حيث:
NDVImax ≈ 0.9 (أقصى NDVI مرصود)
NDVImin ≈ 0.1 (NDVI التربة العارية)
k_ext = معامل الانقراض (0.4-0.7 حسب المحصول)

نموذج مبسط (Beer-Lambert):
LAI = -2.0 × ln(1 - fCover)
```

### منتج Sentinel-2 LAI | Sentinel-2 LAI Product
- متاح من ESA Copernicus مجاناً (Level-2B Biophysical)
- يستخدم شبكة عصبية مدربة على نموذج PROSAIL
- المدخلات: B3, B4, B5, B6, B7, B8A, B11, B12 + زوايا الشمس والرصد
- المخرجات: LAI, FAPAR, FVC, CWC, Cab
- **الأدق للاستخدام المباشر** بدون معايرة محلية

## علاقة LAI بالإنتاجية | LAI and Yield Relationship

### المبدأ | Principle

```
الإنتاجية = PAR × fIPAR × RUE × HI

حيث:
PAR = الإشعاع الفعال ضوئياً (MJ/م2)
fIPAR = 1 - exp(-k × LAI)  (معادلة Beer)
RUE = كفاءة استخدام الإشعاع (جم/MJ)
HI = معامل الحصاد (0.3-0.5 للحبوب)
```

### العلاقة بين LAI ومعامل المحصول Kc | LAI-Kc Relationship

```
Kc ≈ Kc_min + (Kc_max - Kc_min) × (1 - exp(-k_ext × LAI))
```

| LAI | Kc التقريبي | تغطية أرضية % | الإجراء |
|-----|------------|--------------|---------|
| 0.5 | 0.30-0.40 | 15-25% | ري مخفف |
| 1.0 | 0.45-0.55 | 30-45% | ري جزئي |
| 2.0 | 0.65-0.75 | 55-70% | ري متوسط |
| 3.0 | 0.80-0.90 | 75-85% | ري كامل تقريباً |
| 4.0+ | 0.90-1.10 | 85-95%+ | ري كامل |

> **قاعدة عملية**: عندما يصل LAI إلى 3.0+، طبّق قيم Kc الكاملة. أقل من LAI 2.0، قلل الري نسبياً.

## كشف الشذوذ باستخدام LAI | Anomaly Detection

| النمط | السبب المحتمل | الإجراء |
|-------|-------------|---------|
| LAI أقل من المتوقع 30%+ | إجهاد مائي | فحص رطوبة، زيادة ري |
| LAI ينخفض بسرعة | آفة أو مرض | فحص ميداني عاجل |
| LAI أعلى من المتوقع | فائض نيتروجين، خطر رقاد | تقليل N، مراقبة |
| LAI غير متساوٍ في الحقل | تباين تربة أو صرف | إدارة متغيرة المعدل |

## LAI مقابل NDVI: متى تستخدم كلاً منهما | LAI vs NDVI

| المعيار | NDVI | LAI |
|---------|------|-----|
| غطاء متفرق (LAI < 2) | جيد | أقل موثوقية |
| غطاء كثيف (LAI > 4) | يتشبع | **أفضل** |
| [[../irrigation/scheduling\|جدولة الري]] | غير مباشر | **مباشر (ربط Kc)** |
| تقدير الإنتاجية | ارتباط جيد | **أفضل للكتلة الحيوية** |
| البساطة | بسيط (نطاقين) | معقد (نموذج أو عدة نطاقات) |
