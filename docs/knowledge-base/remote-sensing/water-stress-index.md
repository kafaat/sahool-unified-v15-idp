# كشف الإجهاد المائي | Water Stress Detection

الاستشعار عن بعد يمكنه كشف الإجهاد المائي في المحاصيل قبل 7-14 يوماً من ظهور الأعراض بالعين المجردة، مما يتيح تدخلاً مبكراً ويقلل خسائر الإنتاج.

## المؤشرات الرئيسية | Key Indices

| المؤشر | الاسم | المصدر | الاستخدام |
|--------|-------|--------|-----------|
| **NDWI** | مؤشر فرق المياه المعياري | بصري / SWIR | محتوى مائي في الأوراق |
| **NDMI** | مؤشر الرطوبة المعياري | NIR / SWIR | رطوبة الغطاء النباتي |
| **CWSI** | مؤشر الإجهاد المائي للمحصول | حراري | إجهاد مائي مباشر |
| **TVDI** | مؤشر جفاف الحرارة-الغطاء | حراري + NDVI | رطوبة التربة |

---

## NDWI - مؤشر فرق المياه | Normalized Difference Water Index

### المعادلة (Gao 1996) | Formula

```
NDWI = (NIR - SWIR) / (NIR + SWIR)

Sentinel-2:
NDWI = (B8 - B11) / (B8 + B11)

حيث:
B8 = قريب الأحمر (842 نم، 10 م)
B11 = الأشعة تحت الحمراء القصيرة (1610 نم، 20 م)

القيم: من -1 إلى +1
```

### تفسير القيم | Interpretation

| NDWI | الحالة | الإجراء |
|------|--------|---------|
| > 0.4 | رطوبة عالية | طبيعي أو ري زائد |
| 0.2-0.4 | رطوبة كافية | مراقبة |
| 0.0-0.2 | بداية إجهاد | فحص رطوبة التربة، استعداد للري |
| -0.2-0.0 | إجهاد متوسط | **ري مطلوب خلال 24-48 ساعة** |
| < -0.2 | إجهاد شديد | **ري عاجل** + تقييم أضرار |

### تغير NDWI الزمني | Temporal NDWI Change

| التغير بين قراءتين (5 أيام) | الدلالة |
|-----------------------------|---------|
| انخفاض > 0.1 | إجهاد مائي حاد، فحص فوري |
| انخفاض 0.05-0.1 | بداية إجهاد، جدولة ري |
| ثبات (+/- 0.05) | حالة مستقرة |
| ارتفاع > 0.1 | تعافي بعد ري أو مطر |

---

## CWSI - مؤشر الإجهاد الحراري | Crop Water Stress Index

### المبدأ | Principle
النبات المجهد مائياً يغلق ثغوره فيقل التبريد بالنتح وترتفع حرارة الأوراق. كاميرات حرارية ترصد هذا الفرق.

### المعادلة | Formula

```
CWSI = (Tc - Twet) / (Tdry - Twet)

حيث:
Tc = حرارة المحصول (من كاميرا حرارية)
Twet = حرارة المرجع الرطب (ثغور مفتوحة بالكامل)
Tdry = حرارة المرجع الجاف (ثغور مغلقة بالكامل)

القيم: 0 (لا إجهاد) إلى 1 (إجهاد أقصى)
```

### تفسير CWSI | CWSI Interpretation

| CWSI | الحالة | الإجراء |
|------|--------|---------|
| 0.0-0.2 | لا إجهاد | لا حاجة للري |
| 0.2-0.4 | إجهاد خفيف | مراقبة، ري قريب |
| 0.4-0.6 | إجهاد متوسط | **ري خلال 24 ساعة** |
| 0.6-0.8 | إجهاد شديد | **ري عاجل** |
| > 0.8 | إجهاد حرج | ضرر محتمل، ري طوارئ |

### عتبات CWSI حسب المحصول | CWSI Trigger Values by Crop

| المحصول | بدء الري عند CWSI | أقصى CWSI مسموح | الحساسية |
|---------|-------------------|-----------------|----------|
| [[../crops/wheat\|قمح]] | 0.35 | 0.50 | متوسطة |
| [[../crops/barley\|شعير]] | 0.40 | 0.55 | متوسطة-منخفضة |
| ذرة | 0.30 | 0.45 | عالية |
| طماطم | 0.25 | 0.40 | عالية |
| [[../crops/dates\|نخيل]] | 0.45 | 0.65 | منخفضة |
| زيتون | 0.50 | 0.70 | منخفضة جداً |
| حمضيات | 0.35 | 0.50 | متوسطة |
| عنب | 0.45 | 0.60 | منخفضة-متوسطة |
| برسيم | 0.30 | 0.45 | عالية |

> **ملاحظة**: الزيتون والعنب قد يستفيدان من إجهاد مائي متحكم ([[../irrigation/deficit|ري ناقص]]) لتحسين الجودة.

## مصادر البيانات الحرارية | Thermal Data Sources

| المصدر | الدقة | التكرار | التكلفة | الأفضل لـ |
|--------|-------|---------|---------|-----------|
| Landsat 8/9 (TIRS) | 100 م | 16 يوم | مجاني | مقياس إقليمي |
| ECOSTRESS (ISS) | 38-69 م | 1-5 أيام | مجاني | بحث |
| طائرة بدون طيار + كاميرا حرارية | 5-20 سم | حسب الطلب | مكلف (معدات) | مستوى الحقل |
| MODIS LST | 1 كم | يومي | مجاني | اتجاهات كبرى |

> **ملاحظة**: [[sentinel-guide|Sentinel-2]] لا يحمل حساس حراري. CWSI يحتاج بيانات حرارية من مصدر آخر.

## التصوير الحراري بالطائرات | Thermal Drone Imaging

### أفضل الممارسات | Best Practices

| المعامل | القيمة الموصاة | السبب |
|---------|---------------|-------|
| وقت التصوير | 12:00-14:00 (ظهر) | أقصى فرق حراري |
| ارتفاع الطيران | 30-50 متر | توازن بين دقة وتغطية |
| سرعة الرياح | < 10 كم/ساعة | تقليل التبريد غير المنتظم |
| سماء | صافية | بدون غيوم أو ظلال |

### تفسير الصور الحرارية | Thermal Image Interpretation

```
[أزرق/بارد]  → محصول مروي جيداً (ثغور مفتوحة، تبريد نتحي)
[أخضر]       → حالة عادية
[أصفر]       → بداية إجهاد مائي
[أحمر/ساخن]  → إجهاد شديد (ثغور مغلقة، حرارة عالية)
```

| [[ndvi-interpretation\|NDVI]] | NDWI | التفسير | الإجراء |

## ربط الاستشعار بجدولة الري | Linking RS to Irrigation Scheduling

```
1. صورة Sentinel-2 (كل 5 أيام)
       ↓
2. حساب NDWI + NDVI
       ↓
3. تحديد مناطق إجهاد (NDWI < 0)
       ↓
4. مقارنة مع بيانات حساسات التربة (IoT)
       ↓
5. حساب كمية ري إضافية مطلوبة
       ↓
6. تعديل [[../irrigation/scheduling|جدولة الري]]
```

## التكامل مع SAHOOL | SAHOOL Integration

- **حساب NDWI تلقائي**: لكل حقل مسجل من Sentinel-2
- **خرائط إجهاد مائي**: تظليل لوني لمناطق الإجهاد على تطبيق الجوال
- **تنبيهات**: إشعار عند NDWI < 0 أو انخفاض سريع
- **توصيات ري**: كمية مياه إضافية محسوبة تلقائياً
- **ربط مع IoT**: دمج بيانات حساسات رطوبة التربة مع RS
- **تقارير**: ملخص أسبوعي لحالة المياه في جميع الحقول
