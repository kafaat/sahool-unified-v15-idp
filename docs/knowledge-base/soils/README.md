# دليل التربة | Soils Guide

هذا القسم يحتوي على معلومات تفصيلية عن أنواع التربة الرئيسية في منطقة الشرق الأوسط وشبه الجزيرة العربية.

This section contains detailed information about major soil types in the Middle East and Arabian Peninsula.

## أنواع التربة المتوفرة | Available Soil Types

### التربة الرئيسية | Primary Soil Types
- [[sandy|التربة الرملية (Sandy Soils)]] - السائدة في الصحاري والمناطق الساحلية
- [[clay|التربة الطينية (Clay Soils)]] - في الأودية والسهول الفيضية
- [[loam|التربة الطميية (Loam Soils)]] - أفضل أنواع التربة الزراعية

### التربة المتأثرة | Affected Soil Types
- [[saline|التربة الملحية (Saline Soils)]] - شائعة في المناطق الساحلية والمروية
- [[calcareous|التربة الكلسية (Calcareous Soils)]] - منتشرة في شبه الجزيرة العربية

### أدلة مرجعية | Reference Guides
- [[properties-guide|دليل خصائص التربة (Soil Properties Guide)]] - جداول مرجعية سريعة
