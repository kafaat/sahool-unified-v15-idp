#### ثانياً: الاحتياجات الغذائية للمحاصيل - "الصورة الدقيقة"

**1. التحليل الديناميكي لفترة الخصوبة الكاملة**:

```
مثال: القمح - المراحل الأربع الرئيسية
══════════════════════════════════════

مرحلة البذور ──► مرحلة التفريع ──► مرحلة السنبلة ──► مرحلة الامتلاء
     │                │                │                │
     ▼                ▼                ▼                ▼
  N منخفض         N+P+K متضافر      K عالي + P       صيانة
  تعزيز الجذور    دعم الجذع        تجنب الانهيار    وزن الحبوب

النتائج بعد التطبيق:
═══════════════════
• زيادة الإنتاج: 20%
• كفاءة النيتروجين: 32% ──► 58%
```

**2. تقنية SPAD للرصد في الوقت الحقيقي**:

```
┌─────────────────────────────────────────────────────────────────┐
│                   نظام رصد SPAD للنيتروجين                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │

│                                                                 │

│                                                                 │
│  📊 النتيجة: كفاءة النيتروجين من 30% إلى أكثر من 55%           │
│                                                                 │

│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**3. إدارة التباين - "مكان واحد سياسة واحدة"**:

| البُعد | التصنيف | نسبة N:P:K |
|--------|---------|------------|
| **المحاصيل** | الخضروات الورقية | 3:1:2 |
| | جذور الكتل | 1:1:3 |
| | البقوليات | 1:2:3 |
| **التربة** | التربة اللزجة | أسمدة أساسية 60-70% |
| | التربة الرملية | كميات صغيرة متكررة |
| **المنطقة** | الشمال الغربي | توفير المياه والرطوبة |
| | الشمال الشرقي | الري الربيعي للأرز/الصويا |
| | هوانغ-هواي-هاي | مقاومة الجفاف/الفيضان للقمح/الذرة |
