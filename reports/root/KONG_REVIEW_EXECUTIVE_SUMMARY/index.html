    2. satellite-service, weather-advanced, crop-health-ai

    4. تأمين CORS للإنتاج | Secure CORS for production ```yaml origins:

    5. إضافة Security Headers | Add security headers yaml X-Content-Type-Options: nosniff X-Frame-Options: DENY X-XSS-Protection: 1; mode=block

    🟡 متوسطة الأولوية (1 أسبوع) | Medium Priority (1 week)¶

      • OLLAMA_BASE_URL=http://ollama:11434
      • OLLAMA_MODEL=codellama:7b ```

    3. تفعيل TLS/SSL | Enable TLS/SSL yaml KONG_PROXY_LISTEN: "0.0.0.0:8000, 0.0.0.0:8443 ssl" KONG_SSL_CERT: /etc/kong/ssl/server.crt KONG_SSL_CERT_KEY: /etc/kong/ssl/server.key
