# Deps for scripts/export-openapi.py (CI freshness guard)
# متطلبات أداة تصدير OpenAPI
#
# Install with:
#   pip install -c constraints.txt -r requirements/openapi-export.txt
#
# The constraints file pins versions platform-wide; this file is intentionally
# version-free so a single place (constraints.txt) governs upgrades.
#
# Scope: only the dependencies the *exporter* imports at runtime — not the full
# platform dep set. Services whose additional runtime deps are missing are
# skipped with a structured reason by the exporter itself.
# ═══════════════════════════════════════════════════════════════════════════════
