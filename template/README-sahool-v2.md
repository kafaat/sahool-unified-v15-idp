
# SAHOOL v2 — تحسين شامل مع أدوات رسم احترافية

## ✅ ما تم إنجازه

### 1. شاشات جديدة مضافة (3 شاشات)

#### 🎨 أدوات رسم الحقول (DrawingToolsScreen)
- **6 أدوات رسم احترافية:**
  - ⬡ مضلع (Polygon) — بالنقر لإضافة نقاط
  - ▭ مستطيل (Rectangle) — بالسحب
  - ◯ دائرة (Circle) — بالسحب  
  - ✎ رسم حر (Freehand)
  - ✐ تعديل النقاط (Edit vertices)
  - 📏 قياس المسافة (Measure)
- **Canvas تفاعلي** بأبعاد 800×500 مع:
  - شبكة مرجعية قابلة للتبديل
  - التقاط تلقائي للشبكة (Snap-to-grid)
  - تكبير/تصغير (0.5x — 3x)
  - تحريك بالسحب (Alt+Drag)
  - مقابض Vertex للتحرير
- **لوحة جانبية** تحتوي على:
  - تسمية الحقل واختيار المحصول
  - عرض عدد النقاط والمساحة التقديرية (صيغة Shoelace)
  - قائمة الحقول المرسومة مع حذف/اختيار
  - استيراد/تصدير KML/SHP/GeoJSON
- **نصائح تفاعلية** للمستخدم

#### 💰 التمويل والتأمين (FinanceScreen)
- **4 KPIs:** التغطية التأمينية، القروض، العقود النشطة، الأقساط
- **بطاقات عقود** ديناميكية (تأمين/قرض/تمويل)
- **تقييم المخاطر** موسمي (جفاف/آفات/فيضان)
- **فلترة** حسب نوع العقد

#### 🌱 الكربون (CarbonScreen)
- **4 KPIs:** كربون مخزن، هدف سنوي، رصيد اعتمادات، قيمة سوقية
- **مخطط تقدم** بصري مع شريط متحرك
- **مخطط خطي** مقارن (مخزن vs انبعاثات)
- **الممارسات المناخية** مع حالة التطبيق
- **أسواق الاعتمادات** (Verra, Gold Standard, Climate Action Reserve)
- **توافق المعايير** ISO 14064
