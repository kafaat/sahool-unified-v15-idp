# تحقق بيانات الاستشعار عن بعد — حزمة مستقلة

هذه إضافة بحثية قابلة للتشغيل داخل المختبر أو مستودع سهول. لا تغيّر خدمات
الإنتاج، ولا تصحح الصور آليًا، ولا تضيف اتصالًا خارجيًا أو Workflow للنشر.

## التشغيل

استخدم Python 3.12 وبيئة منفصلة. تثبيت الاعتماد قد يحتاج الشبكة؛ تشغيل
الاختبارات بعد التثبيت يعمل على الملفات المحلية فقط.

```bash
python3.12 -m venv /tmp/eo-validation-venv
/tmp/eo-validation-venv/bin/python -m pip install -r tools/eo-validation/requirements.txt
/tmp/eo-validation-venv/bin/python tools/eo-validation/run_checks.py --output-dir /tmp/eo-validation-run-001
```

يجب أن يكون مجلد النتائج جديدًا وخارج هذه الحزمة. لا يعاد استخدام نتائج
تشغيل سابق. يخرج الأمر برمز0 عند نجاح جميع الفحوص، و1 عند فشلها، و2 عندما
تمنع المدخلات أو البيئة بدء التشغيل. تحفظ السجلات ونتيجة JSON في مجلد النتائج.
الحالة `PASSED_OFFLINE_RESEARCH_ONLY` لا تعني اعتماد الإنتاج.

## ما تضيفه الدلتا

- حارس يقارن هوية المنتج والشبكة والتحجيم والأقنعة، ويعرض فرضيات التحويل
  بصورة تشخيصية دون اعتماد إزاحة موحدة لجميع منتجات Element84.
- ثلاث نوافذ يمنية محفوظة من تاريخَي21مارس و6ديسمبر2022، مع بياناتها
  الوصفية الأصلية. ليست حدود مزرعة المستخدم أو عينة ممثلة لزراعة اليمن.
- 38 اختبار وحدة (27 للحارس و11 للبوابة) و18 فحصًا مستقلًا، تشمل رفض اختلاف شبكة SCL والمنتج،
  وتعارض الإزاحة وNoData والمقام الصفري والدعم العددي الفارغ.
- بيان SHA256 للتحقق من ثبات الشيفرة والمدخلات قبل التشغيل وبعده.

الحارس يفصل الانعكاسية السالبة عن NoData ويحتفظ بقيم NDVI خارج[-1،1].
عدادات الجودة متداخلة؛ قناع السحب لا يطبّق تلقائيًا على جميع المقارنات.
المقارنة مع تمثيل C1 اختبار اتساق، وليست تحققًا إشعاعيًا مستقلًا.

## الربط المقترح بالمشاريع

**المختبر:** يشغّل الأمر أعلاه كفحص مستقل، ويجمع `result.json` والسجلات
مع معرف التشغيل ورأس الشيفرة الفعلي. يمنع الانتقال إذا كان رمز الخروج غير0.

**سهول:** تضاف الحزمة أولًا كاختبار مرجعي. يجب مراجعة شيفرة الاستيعاب الحالية
قبل توصيل الحارس أو تعديل سياسة التحجيم. لا يوجد في هذه الدلتا تغيير لمسار
FastAPI أو PostGIS أو حساب المؤشر في التطبيق.

**المستشفى:** حالات مرشحة للتشخيص: تكرار الإزاحة، اختلاف محاذاة SCL، نجاح
كاذب عند انعدام البيانات الصالحة، أو قص NDVI الذي يخفي البواقي. لا تسجّل
هذه الحالات عيوبًا مثبتة في سهول قبل فحص شيفرته؛ يرفق إيصال الاختبار عند
معالجة حالة مثبتة.

**المصنع:** يعاد استخدام أمر التشغيل ونمط الإيصال لاحقًا. لا تنسخ قواعد
Sentinel-2 المتخصصة إلى قلب المصنع، ولا تعتبر هذه الحزمة إطار تحقق عامًا.

## الحدود

هذه ليست قياسات زمن استجابة سهول، ولا اختبارًا لـCDSE أو PostGIS أو الشبكة.
لا تشمل الحزمة المصغرة قياسات VRT والتجميع السابقة؛ تبقى في حزمة الأدلة
الأصلية. أضيفت الحزمة إلى طلب المراجعة #1992 في سهول؛ لا تعني الإضافة اعتماد الإنتاج.
ملفات المصدر والعينات ذات البصمات تمنع التغير العرضي؛ البيان ليس توقيع ثقة
ولا تدقيقًا أمنيًا شاملًا للمدخلات غير الموثوقة.

المصدر: Contains modified Copernicus Sentinel data (2022), accessed through
Element84 Earth Search. تتضمن ملفات `old_item.json` و`c1_item.json` هوية
المنتج وعناوين الأصول التي اشتقت منها النوافذ؛ لا تمثل الإضافة تأييدًا من المزود.

## تصحيح المراجعة الإضافية — النسخة الثانية

تضيف هذه النسخة رفض تعارض CRS على مستوى العنصر وأصول الأحمر وB08وSCL،
وتتحقق من proj:epsg وproj:code. نطاقها المحدود يدعم EPSG المعلن في العنصر
ويفحص الأصول معه؛ ترفض WKT2 وPROJJSON بدل تجاهلهما أو تفسيرهما دون مكتبة مناسبة.

ترفض النتائج غير المنتهية الناتجة عن الفيضان الحسابي بوضوح، ويحسب RMSE
بتطبيع القيم قبل التربيع. تبقى الانعكاسية السالبة وNaN وNoData حالات منفصلة.

لا يكفي رمز خروج ناجح لقبول الفحوص: تثبت expected_tests.json هويات الاختبارات
الثمانية والثلاثين، ويرفض الإيصال أي نقص أو تخطي أو فشل. يفحص المراجع المستقل
الحالات الثماني عشرة بأسمائها دون تكرار، ونجاح كل حالة على حدة، وبصمة الحارس
والمدخلات ومعرف التشغيل المشترك. هذه مطابقة إيصالات داخل تشغيل موثوق، وليست
توقيعًا تشفيريًا أو حماية من مشغّل خبيث يستطيع تعديل الشيفرة والبيان معًا.

نجاح النسخة الأولى كان محدودًا باختباراتها السابقة؛ كشفت المراجعة الإضافية
فجوات حقيقية وأضيفت اختبارات تثبت فشلها قبل الإصلاح ورفضها بعده.

## تشغيل العمليات الفرعية

يستخدم المشغّل مفسّر Python الحالي وملفات فحص ثابتة، مع قائمة معاملات
و`shell=False`؛ مسار النتائج يدخل كمعامل مطلق ولا يفسَّر كشيفرة shell.
الاستثناء الموضعي لقاعدة Semgrep يخص هذا الاستدعاء فقط، بعد اختبار مسار
يحوي رموز shell والتأكد من بقائه اسم ملف حرفيًا. يستخدم `-B` لمنع كتابة
ملفات bytecode دون إنشاء نسخة معدّلة من متغيرات البيئة.
